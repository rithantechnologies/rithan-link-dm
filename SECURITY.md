# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report suspected vulnerabilities privately to:

**rithantechnologies@gmail.com**

Please include enough detail to reproduce the issue, the affected
component or endpoint, and any known impact. Avoid including customer
data, access tokens, passwords, private keys, or other secrets in the
report.

We will review reports and coordinate remediation before public
disclosure where appropriate.

## Secrets

Never commit production `.env` files, Instagram access tokens, Meta app
secrets, token-encryption keys, database passwords, session tokens, or
database backup archives to this repository.
